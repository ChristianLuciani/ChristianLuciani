### 🔬 Main Project — [Kontablo](https://github.com/ChristianLuciani/accounting-esperanto)

**Universal accounting ontology** bridging 195 jurisdictions, IFRS/XBRL, and agent protocols
(MCP, A2A, AP2). Deterministic, graph-based, machine-verifiable financial data exchange.
Published preprint with DOI. v0.3.0 — lossless cross-jurisdictional translation with provenance.
